# Sistema de Gerenciamento de Restaurante

## 🎯 Objetivo do Projeto
Este sistema foi desenvolvido como parte da Avaliação Prática da disciplina de Analise de Projetos e Sistemas (APS). O objetivo é gerenciar o fluxo operacional de um restaurante, desde o controle de mesas e funcionários até a abertura, acompanhamento de produção e pagamento de pedidos.
